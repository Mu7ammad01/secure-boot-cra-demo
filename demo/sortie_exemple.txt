  [ALERTE] HAB event : signature de l'image invalide (CSF)

  ..    U-Boot : partition active A (version 6.6.6)
  [ OK ] U-Boot -> FIT : signature de configuration valide
  [ OK ] U-Boot -> FIT : hash de chaque image conforme
